# H165 -- Ein positionaler GLOB innerhalb einer erklaerten Wurzel verengte nichts (neu, TSK-0126 Merge, Pruefrunde 1 B2)

**Mechanismus.** `gate_test_scope` platzierte ein positionales Wort als EINEN Pfad. Lag es
innerhalb der erklaerten Wurzel, las der Leser das als Verengung — der Satz im Kopf der Datei sagt
das auch so. Ein Glob verengt aber nichts: die Shell ersetzt ihn durch alles, was er trifft, und
`tools/test_*.py` trifft jede Suitendatei der Flaeche.

**Gemessene Kette** (2026-09-05, ausgelieferter Haken als Prozess, JSON auf stdin, `cwd` wie vom
Provider; `_round-scratch/TSK-0126/probe_gate5_glob.py`):

| Zeile | vorher | nachher |
|---|---|---|
| `python -m pytest tools/test_*.py -q` (40 Dateien, 3465 s erklaert) | **rc 0** | **rc 2** |
| `python -m pytest tools/test_[a-z]*.py -q` | **rc 0** | **rc 2** |
| `python -m pytest tools/* -q` | — | **rc 2** |
| `python -m pytest tools/test_x*.py -q` (echte Auswahl) | rc 0 | **rc 0** |
| `python -m pytest tools/test_re*.py -q` (echte Auswahl) | rc 0 | **rc 0** |
| `DELIVERY_RUN=TSK-0126 python -m pytest tools/test_*.py -q` | — | **rc 0** |

**Wie es geschlossen wurde.** Das Gate expandiert ein Wort mit Glob-Zeichen selbst
(`glob.has_magic`, dann `glob.glob` gegen die platzierte Wurzel) und vergleicht die Treffermenge
mit den `members` der Erklaerung — dem Glob, den ein blosser Lauf der Wurzel abdeckt. Die
Treffermenge deckt die Flaeche, wenn sie jedes Mitglied enthaelt. Welche Dateien ein Laeufer aus
einem Verzeichnis sammelt, ist eine Tatsache ueber den LAEUFER, also steht sie als Daten neben
`options_that_narrow`, und beide Enden misst
`.claude/hooks/test_gates.py::test_the_declared_members_are_the_files_the_runner_really_collects`
am laufenden pytest (`--collect-only`, 8,7 s fuer 4697 Tests). Rot ohne den Fix, in einer Kopie
ausserhalb des Repos: Zweig entfernt → 2 failed, `members` entfernt → 2 failed, `members` auf
`test_h*.py` verengt → 1 failed.

**Was stattdessen begrenzt — die benannte UEBER-Verweigerung.** Eine Flaeche ohne `members` bekommt
fuer jeden Glob eine fail-closed Verweigerung mit eigenem Satz statt einer Behauptung, die Zeile
laufe die ganze Flaeche. Die drei Kits liefern gar keine Erklaerung aus, also trifft das ein
Kit-Projekt erst, wenn es selbst eine schreibt; in diesem Repo hat die eine Flaeche mit einem
Verzeichnis als Wurzel ihre `members`, und die zweite (`.claude/hooks/test_gates.py`) ist eine
DATEI — die deckt ein Glob genau dann, wenn seine Expansion diese Datei enthaelt, und dafuer
braucht es keine `members`.

**Die zweite Expansion, gemessen nach der ersten Fassung** (Pruefrunde 2, R2-B4). Mit der echten
Shell und einem `python`-Shim auf `PATH`, der sein `argv` in eine Datei schreibt:

| Zeile | was die Shell dem Laeufer uebergibt | Gate vorher | Gate nachher |
|---|---|---|---|
| `pytest tools/test_*.py -q` | 40 `.py`-Pfade | rc 2 | rc 2 |
| `pytest tools/{test_*,conftest}.py -q` | **41 `.py`-Pfade** | **rc 0** | **rc 2** |
| `pytest tools/test_{board,state}.py -q` | 2 `.py`-Pfade | rc 0 | rc 0 |
| `pytest "tools/test_*.py" -q` | **1 literales Wort** | rc 2 | rc 2 (Ueber-Verweigerung, oben benannt) |

`_brace_expanded` ist rekursiv, trennt an den Top-Level-Kommas und laesst eine unpaarige `{`
literal stehen, wie eine Shell es tut; eine Gruppe ohne Top-Level-Komma gibt es auf und faellt in
den fail-closed Zweig.

**Urteil: GESCHLOSSEN fuer beide Expansionen, die dieser Leser ausrechnen kann, mit zwei
benannten Ueber-Verweigerungen.** Die erste Fassung urteilte „GESCHLOSSEN“, waehrend dieselbe
Klasse als Klammer-Expansion offen stand (Pruefrunde 2, R2-B4) — das Urteil war weiter als die
Messung. Was heute offen ist, steht in der Zusammenfassungszeile: ein Bereich `{1..9}`, den
dieser Leser nicht ausrechnet und darum fail-closed behandelt, und ein QUOTIERTER Glob, der
nichts faehrt und trotzdem rc 2 bekommt (R2-M1).
