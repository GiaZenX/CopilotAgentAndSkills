# H151 -- Die Erklärung, auf der Gate 5 entscheidet, liegt ausserhalb seines eigenen Schutzbereichs (neu, TSK-0121, PR-0004 AC-1)

**Mechanismus.** `gate_test_scope` (Gate 5 dieses Repos) entscheidet auf `tools/test_surface.json`:
welche Flächen erklärt sind, ab welcher gemessenen Dauer sie überhaupt beurteilt werden, und
welche Optionen die Zeile verengen. `_harness.decision_inputs` leitet den geschützten Bereich von
Gate 1 aus den MODULEN ab, die ein Gate beim Entscheiden geladen hat — eine JSON-Datei ist kein
Modul. `CLAUDE.md` sagt dieselbe Sache schon allgemein („`tools/` ist damit nicht mehr pauschal
frei — geschützt ist die Datei, aus der abgeleitet wird, nicht das Verzeichnis. Ein *neues* File
neben ihr bleibt schreibbar"); dies ist der erste Fall, in dem eine solche Datei eine
Gate-Entscheidung trägt.

**Gemessene Kette** (Prozesse gegen ein Stellvertreterprojekt ausserhalb des Repos,
`_round-scratch/TSK-0121/rig/cases.py` und der Knoten
`.claude/hooks/test_gates.py::test_gate5_charges_nothing_to_a_project_whose_suite_runs_in_seconds`):
`judged_above_seconds` über die erklärte Dauer gesetzt → dieselbe Zeile, die vorher **rc 2** war,
ist **rc 0**. Die Datei selbst ist mit `Write`/`Edit` und mit einer Shell-Zeile schreibbar, ohne
dass ein geschützter Pfad berührt wird.

**Urteil: OFFEN, benannte Ausnahme (DEC-0056).** Der Akteur ist der Umsetzer oder der Lead, also
ein Insider, der die Erklärung seines eigenen Projekts ändert — genau die Klasse, für die DEC-0056
sagt, dass kein Härtungslauf angesetzt wird. Begrenzt durch dreierlei: die Änderung steht im
Arbeitsbaum-Diff und damit vor Gate 3, das ohne Evidenz über genau diesen Diff keinen Commit
zulässt; die Erklärung ist ausdrücklich als Knopf gebaut (das ist AC-4, nicht ein Umweg); und
`test_gates.py::test_every_test_file_of_this_repo_lies_under_a_declared_surface` wird rot, sobald
eine erklärte Wurzel keine Testdatei mehr deckt oder eine Suite ausserhalb aller Wurzeln liegt.
NICHT begrenzt: eine gesenkte Schwelle bei unveränderten Wurzeln sieht niemand ausser dem Diff.
