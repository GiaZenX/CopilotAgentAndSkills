# H164 -- Ein Modulname in Backticks wird als Testzitat in ein Loch-Item geschrieben (neu, TSK-0126, DEC-0073)

**Mechanismus.** `tools/migrate_holes.cited_tests` sammelt jede Backtick-Spanne, deren letztes
Glied nach `::` oder `.` mit `test_` beginnt. Ein Modul heisst in diesem Repo nach demselben Muster wie ein Test, also
erfuellt schon sein blosser Name die Bedingung. Die Spanne landet als `regression_tests` im Item,
und erst der Richter danach merkt, dass mehr als ein Test auf den Namen hoert.

**Gemessene Kette** (2026-09-05, `.git`-lose Kopie des gemergten Baums,
`_round-scratch/TSK-0126/migrated_judges.py`):

| Schritt | Ergebnis |
|---|---|
| Migration ueber das gemergte Dokument | rc 0, 152 Items, 152 Prosadateien |
| die sieben migrierten Richter danach | **1 failed, 6 passed** |
| die Meldung | „H159 names test_gates, and 2 tests answer to it in any test file of this repo“ |
| die Spanne in der Prosa von `H159` auf `.claude/hooks/test_gates.py` praezisiert, Migration erneut | **7 passed** |

**Warum das nicht in dieser Runde geschlossen wird.** Die naheliegende Regel — nur `modul::name`
gilt als Zitat — wuerde die Kurzform verbieten, die die bestehenden Eintraege benutzen und die der
Richter absichtlich aufloest (`stem in name`, solange genau ein Test antwortet). Die Unterscheidung
„Modul oder Test“ braucht Wissen ueber die Suite, das dieses Werkzeug heute nicht hat; das ist eine
Aenderung an `migrate_holes.py`, die der Kernel-Strom besitzt.

**Begrenzt durch.** Der Richter ist fail-closed und nennt Nummer und Spanne; die Merge-Runde faehrt
die Migration zuerst als Probelauf gegen eine Kopie ausserhalb des Repos, also wird ein solcher
Eintrag vor dem einen schreibenden Lauf gefunden. In dieser Generation ist die einzige betroffene
Spanne korrigiert, gemessen an 152 von 152 Eintraegen. Was NICHT begrenzt ist: der schreibende Lauf
ist idempotent (`tools/test_migrate_holes.py::test_a_second_run_over_the_same_document_writes_nothing`),
also repariert ein zweiter Lauf ein einmal falsch geschriebenes Feld nicht.

**Urteil: OFFEN, gemessen, bewusst nicht geschlossen.**
