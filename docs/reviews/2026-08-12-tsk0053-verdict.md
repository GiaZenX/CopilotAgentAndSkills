## The two test-hardening residues the verifier measured — now CLOSED
The verifier found both new tests slightly too lenient. Both were hardened (test-only, no bump), lead-
confirmed by reading, red-without-fix measured for the new edges:
- **V1** (`_NEGATED_READ`, test_hooks.py:~4891): the predicate keyed only on "read", so a reworded
  guarantee ("never consults / opens / accesses the transcript") slipped through. Now a negated
  CONSUME-verb set (read/consult/open/access/look at/inspect) — the synonym guarantees are caught,
  while the honest gerund ("consulting it then is legitimate") is deliberately not matched.
- **V2** (entry-ceremony predicate, test_hooks.py:~4972): the old regex accepted a merely DESCRIPTIVE
  sentence ("No trust or approval request happens in this session") as if it were a ban. Now it
  requires a real prohibition in the SAME statement — an imperative "do not <act>" OR a negated
  INVENT-class verb — AND names the ceremony. A factual line no longer passes.
